# Cord19-Visualizations

Este projeto implementa uma pipeline de análise exploratória e visualização da literatura científica sobre
a COVID-19 a partir do conjunto de dados **CORD-19** (release de 02/06/2022).

1. **Projeção multidimensional dos tópicos** (interativa, via `pyLDAvis`).
2. **Relevância temporal dos autores** (Streamgraph das publicações ao longo da
   pandemia).
